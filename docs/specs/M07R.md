## 6. Rules (precise)
- **Glass ladder** (`GlassSurface`): root content wrapped in `Modifier.glassSource(b)` records into a `GraphicsLayer`; glass draws that layer offset by −its own position, clipped to `shape`, with RenderEffect chain = blur 24 dp (`RenderEffect.createBlurEffect`) + saturation 1.7 (`ColorMatrix.setSaturation`) then tint gradient #94_1C2238→#A8_0E1222, 1 dp border #29EDE6D6, top highlight 22 % white. API 31+: that; API ≤30, `backdrop == null`, Reduce Transparency, or battery saver: solid ink3 + 1 dp gold hairline (haldi α .55). Reduce Transparency = new `AppSettings.reduceTransparency: Boolean = false` (UI pref, Settings "Comfort" row next to Bada Text / Reduce Motion; D4). Chandan mood: glass tint #D9FFFBF2, border #E3CFA2. Tilt specular: gradient-highlight offset ±10° from `TYPE_GAME_ROTATION_VECTOR`, low-pass α=0.1, API 33+ only, off under Reduce Motion/battery saver, sensor unregistered `ON_PAUSE`. Never glass on content or glass-on-glass.
- **Dock**: §5 geometry exactly (64 dp, margins 12, r 32, orb column 80 dp, orb 64 dp raised 17 dp, ring r 29/stroke 3 from 12 o'clock clockwise sweep = 360·fractionLeft, end dot). Labels 11 sp/800 (floor), always visible, font scale capped at 1.3× with full label in semantics (M07 decision kept). Tab order Calendar · Kundli · Aaj · Bonds · Bhakti (existing `Tab` enum; no rename). Active: icon tint `lighten(gem)`, glow, −1 dp, 16×3 dp bar 9 dp under label. Chandan: ivory orb, ring #C99A3A, active #B8862A no glow. Width ≥600 dp: dock centred, max width 480 dp (no rail). Hide: `NestedScrollConnection` (down >24 dp cumulative hides, any up shows); hidden when `Dest` is immersive (none exist yet; flag `Dest.immersive`). Haptic `PpHaptic.TAB` on change.
- **Orb state** (pure `feature/aaj/.../ui/OrbLogic.kt`, `fun orbUi(header: Header, days: List<PanchangDay>, now: Instant, fmt: TimeFmt): OrbUi`; inputs = existing `AajModel.ui` (`Content.header`, `days`) + `AajModel.tick`; no engine call, no new logic in `HeaderRule`). C = CHOGHADIYA window containing `now` across `days` (day sunrise→sunset, night sunset→next sunrise). Tone, first match: (1) `header is WaitUntil` (Rahu, Yamaganda, Gulika, Durmuhurta, Varjyam, Bhadra) → AVOID, until = `header.end`; (2) `header is GoodUntil` → GOOD, until = `header.until`; (3) C.code ∈ {AMRIT, SHUBH, LABH} → GOOD, {CHAR} → NEUTRAL (gold ring, lit diya), {ROG, KAAL, UDVEG} → AVOID; until = C.end. Ring always shows C: `fractionLeft = (C.end−now)/(C.end−C.start)` clamped 0..1. No C (polar/`PolarDay`/`Unavailable`) → NEUTRAL, `fractionLeft=null`, ring okay-grey full, diya lit. So orb never contradicts AbhiCard. Strings `orb_a11y_good`="Aaj. Good time now, until %1$s.", `orb_a11y_wait`="Aaj. Better to wait, until %1$s.", `orb_a11y_neutral`="Aaj. Open today's timings." Ring redraws on `tick` (draw phase only, no recomposition of the dock row); tone re-derives when C or header changes. Breathe only when Aaj selected and not reduced motion. Shell gets the model via the existing `AajExtrasHost`/`ShellViewModel` path; Aaj not yet loaded → NEUTRAL.
- **AbhiCard state** from the EXISTING `HeaderRule` output (unchanged): `GoodUntil`→GOOD, `WaitUntil`→WAIT (warn border), `NextGood`/`TomorrowFrom`/`Unavailable`→NEUTRAL; English line = existing M08 header copy; detail = current choghadiya name + "%d min left". Devanagari line `abhi_good_hi`="अभी शुभ समय है", `abhi_wait_hi`="थोड़ा रुकें", none for NEUTRAL (shown in all locales as on PNG; TalkBack reads the English line only). Footer "Traditional interpretation, not a scientific prediction." stays under it.
- **Sky header** (`DS/sky/`): 330 dp; layers bottom→top: image or placeholder (vertical gradient gem@30 %→ink0 plus radial core #E2B33C@12 % at (70 %,30 %)), reading shade (rgb 8,10,20; α .78@0 %, .55@55 %, .12@100 % x), vertical fade to ink0 (α .25@0, .10@45 %, .78@72 %, 1.0@100 % y). Text-safe zone: x≤84 %, y≤62 %: per pixel linear-light RGB scaled so relative luminance ≤ 0.075, feathered over 14 dp (cap blends from 0.075 to none). Enforced by pure `fun capLuminance(r: Float, g: Float, b: Float, cap: Float = 0.075f): FloatArray` applied once at decode on `Dispatchers.Default` for every image on every API (CPU, cached bitmap); placeholders satisfy it by construction. Worst case #F6F1E7 (L≈0.883) on L 0.075 = 7.46:1; the max admissible L for 7:1 is 0.0833. Text 11/800 eyebrow, 30 sp/600 title, 12.5→13 sp/600 meta, shadow 0 1 2 #E6000000. Hora planet: engine hora lord, 112 dp at top-right, x offset +28 dp off-canvas, never intersecting text bounds (layout check in preview).
- **Planets (CRITICAL, B6)**: AGSL on API 33+ (`RuntimeShader`), uniforms `tex` (equirect), `R` px, `sun` (unit, view space: +z toward viewer, +y zenith-up), `rot` rad, `model` (0 Lambert, 1 Lommel-Seeliger, 2 emissive Sun), `soft`, `earthshine`. Per pixel: p=(xy−c)/R, r²=p·p, r²>1→ring/transparent; n=(p.x,−p.y,√(1−r²)); lon=atan(n.x,n.z)+rot, lat=asin(n.y), uv=(fract(lon/2π+.5), .5−lat/π); μ=n.z, μ0=n·sun. Lambert: I=clamp((μ0+soft)/(1+soft),0,1); L-S: I=μ0>0 ? 2μ0/(μ0+μ) : 0 then ×smoothstep(−soft,soft,μ0); emissive: I=1−0.6(1−μ); Moon adds earthshine 0.03·(1−smoothstep(−.02,.02,μ0)) tinted #9AA0B8; alpha=smoothstep(1, 1−1.5/R, √r²). soft: Moon/Mercury 0.02, Mars/Venus 0.06, Jupiter/Saturn 0.15 (tunable, cosmetic). Moon sun vector: i = phase angle, θ = χ−q (bright-limb PA χ, parallactic angle q at user lat/time) → sun=(−sin i·sin θ, sin i·cos θ, cos i). Outer planets: sun=(±sin i,0,cos i), sign by east/west elongation. Saturn rings (radii in Saturn equatorial radii: C 1.239–1.527 α .15, B 1.527–1.951 α .85, Cassini 1.951–2.027 α .10, A 2.027–2.269 α .60), ring normal nR=(0,cos B,sin B) (line of nodes horizontal on screen), hit z=−p.y·cos B/sin B (|sin B|<0.005 → line); front half over disc, back half hidden by disc; planet shadow on ring if ray hits sphere toward sun; ring shadow on disc via t=−(n·nR)/(sun·nR)>0 and hit radius in band → ×(1−α); unlit face ×0.3. Below 33: Canvas fallback (radial gradient offset toward sun; Moon = limb semicircle + terminator semi-ellipse rx=R|cos i| rotated by θ); owner WebP frames later. Spin 2–9 tex px/s, ≤30 fps (frame skip <33 ms), paused when off-screen, not RESUMED, battery saver or reduced motion; `LocalPlanetBudget` lets only the first animated planet per screen animate.
- **Sky geometry (CRITICAL, B5)**: additive pure functions in `:engine` (no existing output changes), fed by the existing `Ephemeris` `EclipticPos(lonDeg, latDeg, distanceAu, …)` for Sun, Moon, planets: elongation cos ψ = cos β cos(λ−λ☉); phase angle from vectors (planet heliocentric = geo planet − geo Sun; cos i = (r²+Δ²−R²)/(2rΔ)); k=(1+cos i)/2; bright-limb PA χ (Meeus 48.5, equatorial via the engine's existing obliquity/apparent conversion — reuse, do not re-derive); parallactic q (Meeus 14.1) at place lat and local sidereal time; Saturn ring B (Meeus ch. 45: sin B = sin i_r cos β sin(λ−Ω) − cos i_r sin β, i_r = 28.075216° − 0.012998T + 0.000004T², Ω = 169.508470° + 1.394681T + 0.000412T², T Julian centuries from J2000; engine-dev confirms constants against the book). `data class PlanetLight(val sunX: Float, val sunY: Float, val sunZ: Float, val ringTiltDeg: Float?)` built in the feature layer from these. MoonMonthGrid phase per cell: elongation at local sunrise from the cached `MonthBundle` day if it carries Sun/Moon longitudes, else tithi midpoint (index+0.5)·12° (D13); no extra engine call per cell.
