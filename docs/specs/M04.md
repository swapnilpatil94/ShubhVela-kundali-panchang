# M04 Calendar and festival engine: spec
## 1. Goal and scope
Pure-Kotlin calendar layer in `:engine` (package `calendar`) on M01-M03: lunations, sankrantis, amanta/purnimanta masa with adhika/kshaya, samvat/samvatsara/ritu/ayana, four regional solar calendars, a data-driven festival DSL with evaluator (incl. Ekadashi + parana), eclipses with local circumstances and sutak. Engine returns ids, codes, dates and Instants only.
Implements MASTER Part 12 "M04"; Part 3 §6 (samvat line), §7 (all but family dates), §8 (adhika/sankranti boundary fixtures, CHANGELOG rule, year budget); Part 2 B2-B6 (engine side); OVERVIEW C12 (R1 regions mr, gu; the four solar calendars are built here, UI flag off until pandit review).
**Out of scope:** family dates (janma-nakshatra, tithi birthday, shraddha: M10 via this DSL); festival names/text (M11 packs), festivals beyond 3.8 (M21); Surya Siddhanta mean-motion mode (Bengali, R2+); Jovian (Barhaspatya) samvatsara; bhadra handling beyond the three 3.6 steps (punchha/mukha) and nakshatra exclusions, punya kala, mahadvadashi, Odia/Telugu/Kannada eras; global central-line type of solar eclipses; tz data (M05); UI, cache (M09).
Tags: **[C1..C6]** CRITICAL (engine-dev), **[B1..B7]** BUILD (implementer). Files disjoint. Order: C1 -> C2 -> C3 -> C4 -> C5; C6 after C2 (parallel to C3-C5). ## 3. Algorithms and rules (all traditional rules VERIFY; restated in our own words, sourceId per rule)
**3.1 Lunations, sankranti, masa [C2].** New moon = start of a TITHI span with index 1, full moon = start of index 16, both from `limbs.spans(TITHI, …)` (M03, bit-equal to limb boundaries). Sankranti = `Gochar.ingresses(Graha.SUN, from′, to′, s)` (sidereal, `s.ayanamsa`) with from′/to′ = from/to rounded down/up to whole UTC days since the Unix epoch (Gochar samples from `from` daily: anchoring makes every instant bit-identical whatever range is asked). Lunation L = [nm_k, nm_{k+1}); S_L = sankrantis with nm_k ≤ at < nm_{k+1}. |S_L| = 1: masa = Masa[into.ordinal]; 0: adhika, masa = Masa[next sankranti after nm_k].into (name of the following month); 2: masa = first.into, kshayaMasa = second.into (VERIFY); > 2 impossible -> `IllegalStateException`. Global (instant-based, place-free). Day label = lunation containing sunrise; a tithi span's label = its own lunation (spans 1..30 tile L exactly).
- `label(L, T, PURNIMANTA)`: T ≤ 15 -> amanta label; T ≥ 16 -> L adhika ? (masa(L), adhika) : (masa(L′), nija) with L′ = next non-adhika lunation (its first name). So the adhika span is identical in both systems and splits the nija purnimanta month (VERIFY). AMANTA = (masa, adhika, kshayaMasa) of L.
**3.2 Samvat, ritu, ayana [C2 Shaka/VS, C3 rest].** Lc = latest nija CHAITRA lunation with newMoon ≤ L.newMoon; Y = UTC year of (Lc.newMoon + 15 d); shaka = Y − 78; vikramChaitradi = shaka + 135 (MASTER); vikramKartikadi = UTC year of (Lk.newMoon + 15 d) + 57 with Lk = latest nija KARTIKA lunation (Gujarat, year from Kartika Shukla 1); samvatsara = floorMod(shaka + 11, 60) + 1 (anchor: shaka 1946 -> 38 Krodhi). samvatsaraTamil = same formula with Y = year of the latest TAMIL MESHA month start ≤ date; bangabda = year of latest BENGALI MESHA start − 593; kollam = year of latest MALAYALAM SIMHA start − 824. Ritu = Ritu[amanta masa.ordinal / 2]. Ayana: UTTARAYANA iff sidereal λ☉ at sunrise ∈ [270°, 360°) ∪ [0°, 90°). All VERIFY.
**3.3 Solar calendars [C3].** `DayLookup` (internal, C3): `sunDay(date)` = M03 `SunDay.of` with the same windows as `PanchangCalculator` (memo); `containing(x)` = date d with sunrise(d) ≤ x < nextSunrise(d) (start from the civil date of x at the caller offset, step ±1). For a sankranti s and P = containing(s): BEFORE_SUNSET (TAMIL): P if s < sunset(P) else P+1. BEFORE_THREE_FIFTHS (MALAYALAM): cutoff = P(sunrise, sunset, 5, 3) (MASTER "3/5 of daylight"); P if s < cutoff else P+1. BEFORE_MIDNIGHT_NEXT (BENGALI): mid = P(sunset, nextSunrise, 2, 1); P+1 if s < mid else P+2. CIVIL (ODIA, and the plain sankranti listing; civil midnight-to-midnight date at the caller offset, so 2024-04-13 21:15 IST -> 04-13, 2025-04-14 03:30 IST -> 04-14): d0 = UTC date of s, d = date of (s + offset(d0)); if offset(d) ≠ offset(d0), d = date of (s + offset(d)). Month start of rashi m = that date; `dateOf` = latest start ≤ date, day = date − start + 1 (1..32). P(a, b, n, i) = M03 3.3 Long-ns arithmetic.
**3.4 Kalas [C4]** (D = [sunrise, sunset], N = [sunset, nextSunrise] of day d; VERIFY each): SUNRISE point; ARUNODAYA [sunrise − 5,760 s, sunrise) (MASTER 96 min); PRADOSH [sunset, P(N, 15, 3)); NISHITA [P(N, 15, 7), P(N, 15, 8)); MADHYAHNA [P(D, 5, 2), P(D, 5, 3)); APARAHNA [P(D, 5, 3), P(D, 5, 4)); MOONRISE = first Moon RISE in [sunrise, nextSunrise) (`RiseSet.find(MOON, …, windowHours = ceil(len/1 h))`), none -> no coverage + MOONRISE_NONE; AHORATRA [sunrise, nextSunrise) (whole panchang day; nakshatra_in_solar_month only). Coverage c(d, X) for span X: point kala -> 1 if X.start ≤ p < X.end else 0; interval -> |X ∩ K| in ns.
**3.5 DSL [B1 parser, C1 types].** File = `{"version":1,"status":ST,"sourceId":SRC,"festivals":[Def+]}`; Def = `{"id":ID,"name":"term:fest_"+ID,"status":ST,"sourceId":SRC,"regions":[REG+],"rule":Rule,"adhika"?:"nija|adhika|both","vratRules"?:[ID*]}`; ST ∈ APPROVED, VERIFY; ID `[a-z0-9_]{1,40}` unique across all files; REG ∈ all, north, west, mr, gu, south, ta, ml, bn, or, te, kn; `adhika` default nija, both when masa = any.
- Rule: `tithi_at` {tithi: T|[T+] (1..30, 16..30 Krishna), masa: lower-case Masa|"any", system: amanta|purnimanta, kala, tie, none}; `weekday_tithi_combo` = tithi_at fields + weekday (Vaar name); `ekadashi` {tradition: smarta|vaishnava, masa, system, paksha: shukla|krishna|both}; `sankranti` {into: Rashi|"any", day: civil|before_sunset|before_three_fifths|before_midnight_next}; `nakshatra_in_solar_month` {nakshatra 0..26, month: Rashi, region: tamil|malayalam|bengali|odia, kala (+ ahoratra), occurrence: first|last|nearest_full_moon, "preceded_in_month_by"?: 0..26}; `fixed_gregorian` {month 1..12, day 1..31}; `relative` {to: ID of a non-relative def in the same file, days: −3..3, ≠ 0}. kala ∈ sunrise, arunodaya, pradosh, nishita, madhyahna, aparahna, moonrise; tie = first|second|max_coverage|{"prefer_nakshatra":0..26,"else":first|second|max_coverage} (MASTER's "prefer_with_rohini" = {"prefer_nakshatra":3,…}); none = containing_start|sunrise|skip; tithi_at may add "bhadra":[STEP+], STEP = {"free_in":kala} | "after_bhadra_before_midnight" | {"next_day_min_ghatis":1..60}.
- Reject (RuleFormatException, code + JSON path, no value): unknown key, missing field, bad range/id, duplicate id, blank sourceId, tithi on ekadashi, `relative` to an unknown/relative id or other file, ahoratra outside nakshatra_in_solar_month, empty `bhadra`, > 262,144 chars, version ≠ 1.
**3.6 Evaluation order [C4].** Range: lunations/sankrantis over [midnight(first) − 40 d, midnight(last + 1) + 40 d]. Per def: (1) candidates; (2) keep first ≤ date ≤ last; (3) dedupe (id, date); output sorted (date, id). Date = civil date of the panchang day (its sunrise), even if the kala lies after local midnight.
- TithiAt: for each lunation L, each T: lab = `label(L, T, system)`; skip unless masa null or masa = lab.masa or masa = lab.kshayaMasa (then KSHAYA_MASA), and adhika policy holds (NIJA: !adhika). X = span T of L. Days d from containing(X.start) − 1 to containing(X.end) + 1; C+ = {d : c(d) > 0}. |C+| = 1 -> d. ≥ 2 -> TIE_BROKEN (+ VRIDDHI_TITHI if SUNRISE): prefer_nakshatra n: C′ = C+ with K(d) touching a NAKSHATRA span n (`limbs`); |C′| = 1 -> it, else apply `else` to (C′ if non-empty else C+); FIRST/SECOND by date, MAX_COVERAGE largest c (equal -> earliest). |C+| = 0 -> NONE_TOUCHED (+ KSHAYA_TITHI if SUNRISE): CONTAINING_START -> containing(X.start); SUNRISE (udaya fallback) -> earliest d with X.start ≤ sunrise(d) < X.end, else containing(X.start); SKIP -> none. kalaWindow = K(d) (point: [p, p]); muhurat = K(d) ∩ X if non-empty interval. SUN_FALLBACK if any C+ day has it; ADHIKA_MASA if lab.adhika.
- **Bhadra steps** (only if `bhadra` given; after d* = the day chosen above). V = VISHTI KARANA spans (M03 `limbs`) over [X.start − 1 d, X.end + 1 d]; free(I) = I ∩ X minus V. Steps in order, first success wins: `free_in k`: free(K_k(d*)) has positive length -> d*, muhurat = its first maximal piece; `after_bhadra_before_midnight`: b = end of the V span overlapping [sunset(d*), nextSunrise(d*)), mid = P(sunset, nextSunrise, 2, 1) of d*; b < mid and b < X.end -> d*, muhurat [b, min(mid, X.end)); `next_day_min_ghatis g`: n = d* + 1, X.start ≤ sunrise(n) and X.end − sunrise(n) ≥ g·1,440 s -> n, muhurat = day kala (MADHYAHNA, APARAHNA): [sunrise(n), min(X.end, sunset(n))), night kala: K(n). A step other than the first -> BHADRA_SHIFT; none succeeds -> d*, muhurat null, BHADRA_UNAVOIDABLE.
- WeekdayTithi: TithiAt, then keep `Vaar.of(date)` = weekday. Relative: each occurrence o of `to` evaluated over [first − |days|, last + |days|] -> date o.date + days, label and flags of o, kala/windows null. SankrantiRule: each sankranti with into match -> 3.3 date, kalaWindow [s, s]. NakshatraInSolarMonth: month m = days start..nextStart − 1; candidates = days with c(d, any span of nakshatra n) > 0 at the kala; `preceded_in_month_by h`: keep d only if the latest earlier day (search 30 d back) with c > 0 for nakshatra h at the same kala is ≥ start; then FIRST/LAST, or NEAREST_FULL_MOON: Fm = full moons with containing(F) in m (none -> the full moon nearest the month's midpoint instant), score(d) = min over Fm of the distance from F to I_d = (n span ∩ K(d)) (0 if inside), smallest wins, equal -> earliest; none -> no occurrence. FixedGregorian: valid dates only (29 Feb in leap years). Ekadashi -> 3.7.
**3.7 Ekadashi + parana [C5].** Per lunation and paksha: E = span 11 (SHUKLA) or 26 (KRISHNA), W = span 12/27; label/masa/adhika as 3.6 (default any/both). C+ = {d : E.start ≤ sunrise(d) < E.end}. D0 = min(C+), or containing(E.start) if empty (KSHAYA_TITHI); VRIDDHI_TITHI if |C+| = 2. SMARTA: F = D0. VAISHNAVA: if E.start > sunrise(D0) − 5,760 s (Dashami touches arunodaya; always true when kshaya) -> F = D0 + 1, DASHAMI_VIDDHA; else F = D0. Parana on F + 1: start = max(sunrise(F + 1), W.start + (W.end − W.start) div 4) (Hari vasara = first quarter of Dwadashi), end = W.end; end ≤ start -> parana null, PARANA_UNDEFINED. kala = SUNRISE / ARUNODAYA, kalaWindow of F. **3.9 Eclipses [C6]** (shadow model VERIFY). Constants: R_E = 6378.137 km, R_M = 1737.4 km, R_S = 695,700 km, AU = 149,597,870.7 km. From geocentric apparent λ, β, distance: π_M = asin(R_E/d_M), π_S = asin(R_E/d_S), s_S = asin(R_S/d_S), s_M = asin(R_M/d_M). Lunar: γ = angle(Moon, antisolar point); ρ_u = (1 + 1/85)π_M + π_S − s_S, ρ_p = (1 + 1/85)π_M + π_S + s_S; skip full moons with |β_M| > 2°; greatest = argmin γ on F ± 6 h (10-min grid, golden-section to 0.1 s); eclipse iff γ_min < ρ_p + s_M; umbralMag = (ρ_u + s_M − γ_min)/(2s_M), penumbralMag = (ρ_p + s_M − γ_min)/(2s_M); kind TOTAL ≥ 1, PARTIAL > 0, else PENUMBRAL; contacts = roots of γ − (ρ_p + s_M) (P1/P4), γ − (ρ_u + s_M) (U1/U4), γ − (ρ_u − s_M) (U2/U3), 10-min grid each side of greatest, Brent to 1 ms. - Local solar: topocentric vectors (C6 `RiseSet.topocentric`), σ = angle, s′ from topocentric distances, search greatest ± 4 h; eclipse iff σ_min < s′_S + s′_M; magnitude = (s′_S + s′_M − σ_min)/(2s′_S); TOTAL if s′_M > s′_S and σ_min ≤ s′_M − s′_S, ANNULAR if s′_M < s′_S and σ_min ≤ s′_S − s′_M, else PARTIAL; C1/C4 at σ = s′_S + s′_M, C2/C3 at σ = |s′_M − s′_S|. Local lunar = global geometry. Interval I = [C1, C4] / [U1, U4] (umbral) / [P1, P4] (penumbral only); visible = first..last instant in I with `RiseSet.crossingDeg(body, place, t, s)` ≥ 0 (null if never).
